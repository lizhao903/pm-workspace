为什么是三栏

左栏导航固定、中栏切视图、右栏抽屉承载详情与 AI。所有操作在一页完成，不跳页 = 轻量化的前提。

右栏复用

「详情 / AI 助手 / 活动 / 关联图」共用一个抽屉。AI 不单独开页面，永远贴着当前选中的对象，上下文天然就有。

Agent 草稿区

AI 的写操作一律渲染成橙色草稿卡，有 采纳 / 编辑后采纳 / 忽略 三个动作，确认后才落库。

状态栏

暴露 DB 体积、索引量、Agent 运行进度、备份时间。本地工具要让人对数据有掌控感。

快捷访问是独立页

侧栏只留一个入口，整页做分组网格与拖拽。三种目标：外链 / 内跳 / 动作。外链支持 {{title}} 等变量，选中需求后可直接跳 Jira 搜同名内容。置顶项上顶栏。

响应式降级

<1280px 右栏改为浮层；<960px 左栏收成图标条；移动端只保留「快速捕获 + 今日 + 搜索」三件事。

键盘优先

Cmd K 命令面板、C 新建、J/K 上下选、Space 开关右栏、1-5 切视图。
