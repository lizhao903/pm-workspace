# 司南的启示 · 教学思路（原始素材）

## 一、创设情境

1. 古代将军南下情境，辨别方向的方法。
学生问ai，规范询问语言，初步掌握ai用法。可以用看太阳、看星星等方法辨别。
2. 浓雾环境，没有办法的时候，运用天然磁石制作磁铁。

## 二、新授

1. 实验，验证条形磁铁具有指示南北的作用。
2. 古人还用了类似的方法、悬挂法、水浮法等验证磁铁具有指示南北的作用。学生尝试，记录。
3. 探究磁铁为什么具有指示南北的性质。猜想可能的因素。
4. 归纳后，发现有可能是地球内部有磁铁结构。用网页模拟操作，当地球内部有磁铁的时候司南能够指示南北，地球内部没有磁铁的时候司南失灵。

## 三、拓展提升

1. 磁铁能够指示南北的原因继续探究。
2. 指南针的应用。

## 附：已完成的模拟实验设计事实

来源：`presentation/public/sinan-sim.html`（由上一阶段交付的 `sinan-sim/index.html` 迁移，单文件离线网页；构建产物为 `dist/sinan-sim.html`）。以下为可挂到画面上的真实细节，非虚构素材。

- 器物：用红端为 N 极、蓝端为 S 极的磁针代替勺形司南，中心带转轴。
- 变量：模型假设可切换为「地球内部有巨大磁铁」与「地球内部无巨大磁铁」，内部条形磁铁随之显示或消失；不显示磁感线。
- 内部磁铁形态：沿地轴竖直贯穿整个地球剖面，两端贴合地表，长度等于地球直径；地理北极侧为蓝色 S 极、地理南极侧为红色 N 极，与地理南北极方向相反；无磁铁时以同尺寸虚线空框对照。
- 操作：拖动磁针沿地表圆弧移动，拖动时朝向被随手带偏；松手后观察 N 极朝向。
- 有磁铁：弹簧阻尼摆动回正，N 极恒指北，偏离南北 0 度；换到地表任意位置结果一致。
- 无磁铁：带惯性随机停下，偏离南北 30 至 90 度，各处朝向散乱，不显示磁感线。
- 切换假设：无切到有时磁针立即缓缓回正；有切到无时保持当前朝向不动。
- 记录：每次松手自动写入「假设 / 位置 / 偏离 / 是否指南北」，两组各满 3 次解锁「我的发现」，页面不给标准答案。
- 科学性口径：地球内部并不存在一块永久磁铁，真实成因是地球外核导电流体产生的地磁场；「有巨大磁铁」是等效假设模型，用于验证磁性作用是必要条件，不是物理事实。归纳只到「周围存在看不见的磁性作用」，真正原因留给拓展环节。
- 验证数据：每种假设各 2000 次数值模拟，有磁铁组 2000 次全部回正，无磁铁组 0 次沿南北；无卡死，平均收敛 1.00 秒与 0.89 秒。浏览器实测记录为有磁铁组 3 次全部沿南北、无磁铁组 0 次沿南北。
- 交付形态：单文件离线网页，内联 SVG 与鼠标触屏通用的拖动事件，零外部依赖。
